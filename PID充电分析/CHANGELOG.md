# CHANGELOG

> 以下条目转录自仓库内 `magisk模块/VERSION`。`module.prop` 当前版本为 `4.4`，但 `VERSION` 最新条目只到 `4.3`，4.4 的变更内容暂无记录。

## 4.4

- 变更内容暂无记录（`module.prop`：`version=4.4`、`versionCode=251209`）。

## 4.3

- 修复天玑不生效问题，去除天玑 GPU 调频，修复夜间模式触发导致最低功率失效问题，优化冗余判断逻辑。

## 4.2

- 修复 GPU 频率表赋值不生效的问题，优化了文件检测逻辑更加省电。
- 默认不再关闭 `mi_thermald` 服务，需要手动关闭：自行执行 `setprop ctl.stop mi_thermald`，或运行模块执行按钮功能 2（每次重启都需要执行），或修改模块内 `service.sh` 将最后一行解除注释。

## 4.1

- 修复旁路模式复原问题，去除部分骁龙电池负优化（垃圾电池有鼓包风险）。

## 4.0

- 新增 CPU 和 GPU 统一调频，内置 3 档调频曲线，不可更改；使用该模式需要自行去除温控（推荐使用 Scene 的「丧心病狂」后重启手机）。
- 新增模拟旁路模式，通过配置 `GAME_list` 添加游戏包名触发游戏旁路。

## 3.1

- 新增兼容模式，部分电流失控机型使用（比如小米 13 请打开兼容模式，0 为关闭，1 为开启）。

## 3.0

- 更新辅助模块新增使用特性，优化执行 action 动作按钮功能实现配合。
- 新增最低充电功率配置（设置了不代表就能持续保持，请结合实际需求按要求设置）。
- 辅助模块使用方式见 https://gitee.com/DRDAI/mithermal_change 。

## 2.8

- 整合日志操作，日志超过 10 MB 自动清理。
- 整合配置操作：配置存在则不对配置进行更改，保留配置文件设置（该功能暂未实现）；配置不存在（第一次刷入）则自动生成配置。
- 修复新机型匹配温控不到的问题，增加功能一的选择逻辑。

## 2.7

- 兼容小米 15 系列。

## 2.6

- 执行按钮增加三种功能：功能一为 2.5 版本默认功能；功能二暂时关闭温控，无需重启；功能三恢复暂时关闭的温控，无需重启。
- 执行功能在 KernelSU 最新版本下测试通过，其余模块管理工具请自行测试。
- 说明：KernelSU 对 action 执行的 shell 有些许兼容性问题，已用特殊办法绕过并测试成功。

## 2.5

- 通用性升级：模块管理界面增加执行按钮，点击默认去除日用场景充电温控 47.5 ℃。

## 2.4

- 修复去温控时异常值导致模式未切换的问题。

## 2.3

- 修复日志异常。

## 2.2

- 验证携带温控时的回温参数，应比 2.0–2.1 好一点。
- 简化内测更新步骤：内测热更新脚本用于 Q 群内测；在群内下载带版本日期的模块，在模块目录下运行脚本即可，无需重启手机。

## 2.1

- 修复一些 2.0 的 bug，退出介入电量提高到 100。

## 2.0

- 优化控制精度，静息保守可能在 ±0.2（无脑去温控将吃不上本次优化，硬件限制）。
- 优化充电 / 不充电日志排版，不同状态删减部分内容。
- PID 模块在电量到达 95 后退出介入状态。
- 优化接近升温较慢的问题（尽可能快地将温度爬升至目标温度；部分内阻较低的新电池温度不一定能上升到目标温度）。
- 优化机型获取。内阻测试模块一同打包进模块内，需要的自行运行（记得给执行权限）。

## 1.9

- 优化部分代码结构，增添日志功能细节。

## 1.8

- 更换亮灭方案，解决路径导致不生效、无 log 的问题。

## 1.7

## 1.6

- 修复高通老机型 bms 电流失控问题，也许对新机型也有用。

## 1.5

- 修复模块 `PID_` 运行时资源随时间变大的问题。

## 1.4

- 修复开机不执行的问题。

## 1.3

## 1.2

## 1.1

## 1.0
