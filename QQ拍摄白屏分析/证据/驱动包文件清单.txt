驱动包文件清单与分类
====================
包名：GPU_v@837.0.6M-KSU.zip
module.prop：id=GPU_UPDATE，name=Adreno™ GPU Driver，version=v2，versionCode=v837.0.6，description=v@0837.0.6 Kernel 5.4+ Only
安装类型：KernelSU / Magisk 模块（system/vendor 覆盖挂载）

一、安装做的事（customize.sh 解码后）
1. 读取 getprop ro.soc.model / ro.vendor.qti.soc_model，只允许 SM8550/SM8475/SM8425/SM8450/SM8350/SM8250/SM8150/SM7550/SM7475/SM7435/SM7450/SM7325/SM7350/SM6450/SM6115/SM6225/SM6150/SM4450/SM4375（SM6375 且 board=blair 除外）。
2. 内核 < 5.4 仅警告；Android SDK < 34 直接 abort，< 36 警告“可能无法在 Android <16 启动”。
3. vendor 只有 arm64-v8a 时删除 32 位 system/vendor/lib。
4. 拷贝 qgl_config.txt 到 /data/vendor/gpu/qgl_config.txt。
5. set_perm_recursive：.so 设为 0755 0644 u:object_r:same_process_hal_file:s0；permissions xml 设为 vendor_configs_file。
6. 清空所有应用的 shader / graphitecache / gpucache、/data/system/graphicsstats、dalvik-cache、package_cache、resource-cache。
7. 删除其它 GPU 模块目录（gpu_driver_free、gpu_driver、adreno_driver、adreno_vk_gpu_driver、adreno_gl_gpu_driver）。
8. 恢复模式分支 META-INF/rec.sh 额外改写 /vendor/etc/public.libraries.txt（libOpenCL、libgpumemtracer、libgpuservice、gpu++）。

⚠ 危险动作（本次白屏的直接原因）
  第 6 条中的：
    find /data/data/* -iname "*shader*" -exec rm -rf {} +
  是递归匹配 /data/data 下任意路径名含 "shader" 的文件或目录，不只 cache。
  QQ 光影相机的动态资源包路径：
    /data/user/0/com.tencent.mobileqq/app_lib/qq_bundle_new/BASIC_64/<hash>/assets/shaders/essl/
  目录名 shaders 命中 *shader*，被整体删除。
  真机日志显示 vs_simple.bin / vs_epm.bin / vs_boxblur.bin / fs_adjustments.bin
  全部 FileReader: Failed to open file，随后 vertex shader is invalid / ReadSample error。
  详见同目录 logcat关键片段.txt。

  uninstall.sh 也含同一行（逐行原文，无条件判断）：
    1  find /data/user_de/*/*/*cache/* -iname "*shader*" -exec rm -rf {} +
    2  find /data/data/* -iname "*shader*" -exec rm -rf {} +
    3  find /data/data/* -iname "*graphitecache*" -exec rm -rf {} +
    4  find /data/data/* -iname "*gpucache*" -exec rm -rf {} +
    5  find /data_mirror/data*/*/*/*/* -iname "*shader*" -exec rm -rf {} +
    6  find /data_mirror/data*/*/*/*/* -iname "*graphitecache*" -exec rm -rf {} +
    7  find /data_mirror/data*/*/*/*/* -iname "*gpucache*" -exec rm -rf {} +
  KernelSU 文档说明 uninstall.sh 在模块删除前执行；卸载时 QQ 的 shaders 目录
  已被安装脚本删掉，find 对 QQ 已无可删，所以“卸载恢复”不等于“卸载脚本不删”。

  本机模拟复现（2026-11-11）：
    mkdir -p sim/app_lib/qq_bundle_new/BASIC_64/hash/assets/shaders/essl
    touch    .../assets/shaders/essl/vs_simple.bin  .../assets/material.json
    find sim -iname "*shader*" -exec rm -rf {} +
  结果：shaders 目录被整体删除，material.json 保留 —— 与 QQ 日志中
  “shader 文件缺失、material/template.json 正常” 的现象完全一致。
