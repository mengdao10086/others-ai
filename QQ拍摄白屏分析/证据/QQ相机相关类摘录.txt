八、GPU 白/黑名单机制（com.tencent.aelight.camera.ae.util.j）
  存在按 GL_RENDERER 字符串（Adreno/Mali/PowerVR）解析型号的规则：
    private void w(JSONObject o) {
        for (String verdor : o.getString("verdor").split(";"))
            if (this.a.contains(verdor)) v(o.getJSONObject(verdor));
    }
  但 this.a（GPU 信息）只在 SDK < 24 的分支里用
  com.tencent.mobileqq.opencl.OpenclInfoManager().a() 填充；
  SDK >= 24 时 p(...) 直接走机型/配置判断，this.a 保持 ""，w() 实际不生效。
  结论：本机（Android 16 级）不会因 GPU 型号切换渲染路径；
        按机型黑名单（blackList）仍可能生效，但 K60 未被点名。
  GL_RENDERER 还会被 com.tencent.aelight.camera.ae.flashshow.util.d 读取，
  但只用于上报/缓存 device_gpu_name，不参与渲染分支。
